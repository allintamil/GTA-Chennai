# Grand Theft Auto: Chennai  (3D)

An unofficial, fan-made third-person open-world crime game set in a stylised Chennai.
HTML5 + JavaScript + [Three.js](https://threejs.org) (loaded from cdnjs, so you need an internet connection the first time).
No build step. All models, textures and audio are generated in code.

## Run
Double-click `index.html`, or serve the folder: `python -m http.server 8123` → http://localhost:8123.
Chrome / Edge / Firefox on a desktop with a GPU. Keyboard + mouse. Click the game to capture the mouse (Esc releases it and pauses).

## Controls
| Input | Action |
|---|---|
| W A S D | Move (camera-relative) / drive |
| Mouse | Look / orbit camera |
| Left click | Shoot / punch (aim assist locks onto nearby hostiles) |
| Right click (hold) | Aim over the shoulder |
| Shift | Run |
| E | Enter / exit vehicle (hijack if occupied), talk to markers, shop, rest at home |
| Space | Handbrake |
| H | Horn (toggles the siren in a police jeep) |
| Q, wheel, 1–6 | Switch weapon |
| F | Throw a nattu vedi (country bomb) |
| R | Toggle "Kuthu FM" radio |
| N | Auto-driver side job (auto-rickshaw or cab) |
| M | City map · Esc pause |

## What's in it
* **3D city** – Marina Beach & lighthouse, Chennai Central with its clock tower, Fort St. George, Chepauk stadium,
  Kapaleeshwarar gopuram + tank, T. Nagar, Koyambedu market, Guindy park, Cooum & Adyar rivers with bridges,
  port, airport with landing jets, fishing hamlet. English + Tamil district names and shop signs.
* **Rendering** – extruded buildings with window atlases that light up at night, real-time sun shadows,
  day/night cycle with sky and fog, monsoon rain, street-lamp light pools, headlight beams, animated sea,
  particle fire/smoke, skid marks, explosions with dynamic light.
* **Characters & vehicles** – rigged low-poly people (civilians, saree, police, gang, player) with walk/aim/melee animation;
  auto-rickshaws, classic cabs, hatchbacks, SUVs, police jeeps, MTC buses, bikes with riders, decorated lorries.
* **Simulation** – left-hand traffic with signalised junctions, pedestrians, 5-star police response (jeeps, foot cops, arrests),
  vehicle physics & damage, six weapons.
* **Story** – 5 missions from Maran Anna (delivery, collection, street race, bookie chase, Marina showdown) + auto-driver job.
* Day/night, procedural audio and a procedural radio, save/load (rest at home).
